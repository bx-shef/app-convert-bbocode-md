## Сначала: снять блокировки

Это не новые функции, а то, что уже написано и ждёт одного действия.

| Что | Чего ждём | Что получим |
|---|---|---|
| Проверка в тестовом портале Bitrix24 | доступ к порталу | половина карты проекта перестанет быть «не проверено» |
| **Починить непереведённые языки** (сейчас показывают служебные названия строк вместо текста) | ничего не ждём — нужна настройка запасного языка в коде | портал на любом из 19 языков перестанет выглядеть сломанным; **делать в первую очередь** |
| Перевод интерфейса на 17 языков | ключ сервиса перевода DeepSeek (`DEEPSEEK_API_KEY`), дальше — команда `pnpm translate-ui` | приложение заговорит на языке пользователя портала, а не по-английски |
| Включение счётчика посещений | номер счётчика | видно, пользуются ли публичной страницей |
| Кнопка «Сообщить об ошибке конвертации» | внешний обработчик и его адрес | пользователи начнут присылать примеры неверной конвертации |
| Предложение оценить приложение | публикация в Маркете Bitrix24 | отзывы в карточке приложения |
| Отчёты о работе в Telegram | ключи бота и канала | регулярная сводка без ручных запросов |

## Потом: полезное для пользователя

| Что | Зачем | Сложность |
|---|---|---|
| Поддержка файлов с Диска (`[DISK File=…]`) | сейчас такая вставка остаётся текстом и выглядит непонятно | средняя; сначала нужен пример из портала |
| Подстановка имён в упоминаниях | сейчас имя берётся из самого текста; можно подтягивать актуальное из портала | средняя |
| Подстройка под тему портала | приложение будет автоматически светлым или тёмным, как портал | пока невозможно: портал не сообщает свою тему |
| Проверка справа налево (арабский) | убедиться, что интерфейс не разъезжается | низкая |
| Больше объектов портала | например, описания сделок или элементы списков | средняя, по запросу |

## Потом: надёжность и безопасность

| Что | Зачем | Заметка |
|---|---|---|
| Включить заголовки безопасности в боевой режим | сейчас они работают в режиме наблюдения — нарушения не блокируются | сначала проверка в портале, чтобы ничего не сломать. **Если к тому моменту включена обратная связь** — сначала разрешить её обработчик в заголовках (см. раздел ниже), иначе отправка перестанет работать |
| Сбор нарушений безопасности | сейчас они видны только в консоли браузера у пользователя | нужен отдельный внешний приёмник |
| Прогнать откат и проверку на живом сервере | команды написаны, но вживую не запускались | делается за один заход |
| Жёсткая фиксация версий внешних действий сборки | защита от подмены сторонних компонентов | нельзя сделать из текущего окружения |
| Уменьшить размер Docker-образа | в образ попадает лишнее (документация, тесты) | нужен запуск сборки с Docker |
| Постоянная проверка зависимостей на уязвимости | ловить проблемы сразу, а не при обновлении | меняет правила проверок — на решение владельца |

## Потом: доработки обратной связи

Актуально только после включения кнопки «Сообщить об ошибке».

- Ограничить общий размер отправляемого сообщения (сейчас ограничено только отдельное поле).
- Разрешить обращения к обработчику в настройках безопасности сервера.
- Добавить проверку самой формы отправки в автотесты интерфейса.

## Что решено не делать

| Что | Почему |
|---|---|
| Своя серверная часть | приложение намеренно работает без сервера — так проще размещать и нечего взламывать |
| Свои повторы неудачных запросов к порталу | их уже делает библиотека Bitrix24; свои поверх мешали бы ей и могли задвоить сохранение |
| Второй счётчик посещений (Cloudflare) | он не умеет отключаться внутри портала, а это наше требование; остаётся выключенным |
| Хранение любых секретов внутри приложения | код страницы виден всем; секреты живут только на стороне сервера или обработчика |
