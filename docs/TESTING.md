# План тестирования — конвертер BBCode ↔ Markdown ↔ HTML

> Last reviewed: 2026-07-23

Трёхуровневый план проверки: от «вообще стартует» до «со всех сторон». Уровни идут
по возрастанию охвата и стоимости — каждый следующий имеет смысл, только когда
предыдущий зелёный. Живые REST/портальные сценарии автотестами не покрыть — они
вынесены в раздел «Портальный QA».

## Уровень 1 — просто запустить (smoke)

Цель — стартует ли вообще. Внешних сервисов не нужно (чистый SPA).

| Шаг | Команда / действие | Что ждём |
|---|---|---|
| Статика собирается | `pnpm generate` (или `pnpm build`) | Сборка без ошибок |
| Dev-сервер | `pnpm dev` | Поднимается на `:3000`, консоль без ошибок |
| Главная | `/` | Три редактора (Markdown/BBCode/HTML) + превью; не белая |
| Install вне фрейма | `/install` | Mock-прогресс install-флоу; не белая (SDK молча no-op) |
| Виджет вне фрейма | `/widget/im-textarea` | Рендерится; SDK no-op вне портала |

## Уровень 2 — просто прогнать (happy-path)

Цель — один раз пройти штатные сценарии.

| Шаг | Команда / действие | Что ждём |
|---|---|---|
| Полный гейт | `pnpm check` (= `make check`) | lint + typecheck + vitest зелёные (209 тестов) |
| Визуальный e2e | `pnpm build && pnpm test:e2e` | Playwright зелёный + dark-mode contrast-guard; скриншоты в `e2e/output/` |
| Конвертация | вставить BBCode → смотреть MD/HTML/превью | Все панели пересчитываются; превью санитизировано и корректно |
| Печать | кнопка печати | Открывается системный print-preview (скрытый iframe) |
| REST вне портала | тулбар Load/Save | Демо-уведомление (гард `isUseB24` → `notifyDemo`), не падает (`B24NotReadyError` — предохранитель в `useB24Rest` при REST без init) |

## Уровень 3 — со всех сторон (полное покрытие)

| Проверка | Где | Ожидаемо | Метка |
|---|---|---|---|
| Roundtrip всех тегов | `tests/roundtrip.test.ts`, `table.test.ts` | bb→md→bb, md→html→md стабильны; таблицы, вложенность, `[*]`, code-literal | [авто] |
| Санитайзер | `tests/sanitize-html.test.ts` | `<script>`/`on*`/`javascript:` вырезаются до DOM (превью/печать) | [авто] |
| Raw-HTML не протекает | вставить `<ul>`/`<table>`/`<b>` в HTML-панель | Конвертится в BBCode, а не в текст | [авто] + ручной |
| Стилевые + упоминания | `[color]`/`[size]`/`[font]`, `[USER]`/`[DEPARTMENT]` | Round-trip через `<span>`-carrier; чип в превью | [авто] + ручной |
| i18n | смена локали | Строки переключаются; прочие 17 локалей → fallback на `en` | ручной |
| Тёмная тема | toggle | Контраст держится (e2e guard) | [авто] |

## Портальный QA (нужен живой тестовый портал Bitrix24)

Автотестами не покрывается — в `docs/project-map.md` это шаг 7 (⛔). Прогонять
установкой приложения в реальном тестовом портале. Отмечать [ ] по мере прохождения.

- [ ] **Install** — открыть приложение в портале → страница `/install` доходит до «Готово» без ручной донастройки; кастом-поля/скоупы (`task`, `crm`, `log`) на месте.
- [ ] **Load/Save задача** — открыть из карточки задачи: `DESCRIPTION` грузится в редактор → правка → Save → в задаче обновилось (учтён флаг BBCode/HTML).
- [ ] **Load/Save CRM-комментарий** — `COMMENT` ↔ MD, сохранение обратно.
- [ ] **Load/Save пост Ленты** — `DETAIL_TEXT`; заголовок сохраняется (get-перед-update).
- [ ] **Виджет IM_TEXTAREA** — панель над полем ввода чата: загрузить текст чата → MD → правка → «Вставить» → MD→BBCode уходит в поле ввода.
- [ ] **Попап рейтинга** — при заданном `NUXT_PUBLIC_MARKETPLACE_SLUG` и достаточной активности (copy/save ≥ порога) на входе в портал появляется модалка «Оцените»; «Оценить» открывает слайдер листинга Маркета; «Позже» откладывает (кулдаун), закрытие крестиком/Esc тоже считается откладыванием; «Больше не спрашивать» — не показывает. Вне портала / при пустом слаге — попапа нет.
- [ ] **Мобильное приложение Б24 (WebView)** — виджет открывается в мобильном портале; чтение/вставка работают; кнопка «Печать» скрыта (в WebView нет print/Clipboard — `isBitrixMobile`).
- [ ] **Mixed-Content / редирект** — `/widget/im-textarea` открывается по `https` без Mixed-Content (фикс `absolute_redirect off`, #74). В консоли нет `http://…` редиректов.
- [ ] **POST-обработчик** — приложение открывается из портала (POST) без белого «405» (`error_page 405 =200`).
- [ ] **CSP** — консоль без `Refused to…`/CSP-violations на `/`, `/install/`, `/widget/im-textarea` (сейчас CSP в Report-Only, #78 — при флипе на enforce перепроверить; при включённой аналитике проверить `connect-src`/`script-src`).

## Definition of Done для UI

После любой UI-правки: прогнать e2e (`pnpm build && pnpm test:e2e`) и **посмотреть
глазами** на скриншоты в `e2e/output/` — не доверять «собралось без ошибок»
(норма перенесена из `ai-price-import` `VISUAL_VERIFICATION.md`). При правке
интерфейсов сверяться с документацией Bitrix24 UI: <https://bitrix24.github.io/b24ui/>.
