## Метки состояния

| Метка | Значение |
|---|---|
| ✅ **готово** | сделано, покрыто автотестами, проверено вживую |
| 🧪 **не проверено** | код готов и автотесты зелёные, но вживую в портале не проверялось |
| ⏸ **отложено** | сознательно отложено; причина указана |

Причин у метки 🧪 две, и они разные:
- **нет тестового портала Bitrix24** — всё, что связано с живым порталом, проверяется
  только руками (список — ниже, «Проверка в портале»); это большинство таких меток;
- **не задана настройка** — три дополнительные функции ждут одного значения от
  владельца и включатся сразу после этого, портал для них не нужен.

## Что это за приложение

Конвертер текста между тремя форматами: **BBCode Bitrix24 ↔ Markdown ↔ HTML**.
Опорный формат — Markdown, любая конвертация идёт через него.

Работает в двух видах: как обычный сайт и как приложение внутри портала Bitrix24
(кнопка у поля ввода чата + панель работы с задачами, CRM и Лентой).

## Части приложения

### Ядро конвертации

| Часть | Что делает | Состояние |
|---|---|---|
| Разбор BBCode | превращает текст Bitrix24 в структуру для конвертации | ✅ готово |
| BBCode → Markdown | перевод в опорный формат | ✅ готово |
| Markdown → BBCode | обратный перевод, в том числе для чата | ✅ готово |
| Markdown ↔ HTML | третий формат в обе стороны | ✅ готово |
| Очистка HTML | вырезает опасное до показа на экране | ✅ готово |
| Поддержка тегов оформления | цвет, размер, шрифт | ✅ готово |
| Упоминания сотрудников и отделов | `[USER]`, `[DEPARTMENT]` | ✅ готово |
| Кнопки чат-бота | `[SEND]`, `[PUT]`, `[CALL]` | ✅ готово |
| Файлы с Диска (`[DISK File=…]`) | проходит как обычный текст | ⏸ отложено — нужен пример из реального портала |

### Интерфейс

| Часть | Что делает | Состояние |
|---|---|---|
| Экран конвертера | три поля ввода + предпросмотр; на телефоне — вкладки | ✅ готово |
| Предпросмотр | показывает готовый результат | ✅ готово |
| Печать | Markdown → готовый к печати документ | ✅ готово |
| Тёмная тема | переключение оформления | ✅ готово |
| Тексты интерфейса | русский и английский вручную | ✅ готово |
| Остальные 17 языков | сейчас вместо текста показывают технические названия строк | ⚠️ **дефект** — см. пояснение ниже |

> **Дефект: непереведённые языки показывают не английский текст, а служебные
> названия строк** (например, `page.index.ui.title` вместо «Конвертер»). Причина:
> запасной язык не настроен, поэтому при отсутствии перевода подставлять нечего.
> Затронуты 17 языков из 19 — в них заполнено 4 строки из 87. Лечится двумя
> способами: настроить подстановку английского (быстро, вернёт нормальный вид
> сразу) и/или перевести строки. Пока не сделано — портал на немецком, французском
> и т. п. выглядит сломанным.

### Связь с Bitrix24

| Часть | Что делает | Состояние |
|---|---|---|
| Подключение к порталу | соединение приложения с Bitrix24 | 🧪 не проверено |
| Страница установки | регистрирует кнопку в чате | 🧪 не проверено |
| Кнопка в чате | забрать текст из чата, вернуть обратно | 🧪 не проверено |
| Задачи: загрузка и сохранение | описание задачи ↔ редактор | 🧪 не проверено |
| Комментарии CRM: загрузка и сохранение | комментарий ↔ редактор | 🧪 не проверено |
| Посты Ленты: загрузка и сохранение | текст поста ↔ редактор; заголовок сохраняется | 🧪 не проверено |
| Ограничение ожидания ответа | если портал молчит минуту — понятное сообщение вместо зависания | ✅ готово |
| Отмена запроса на полпути | — | ⛔ заблокировано — Bitrix24 SDK этого не умеет |
| Определение темы портала | подстройка под светлую/тёмную тему портала | ⛔ заблокировано — портал не сообщает свою тему |

> **Остаточный риск (следствие того, что запрос нельзя отменить).** Если портал
> не ответил за минуту, кнопка разблокируется, а прежний запрос может всё ещё
> выполняться. Повторное нажатие «Сохранить» способно отправить две записи для
> одного объекта. Опасности для данных нет: сохраняется целиком одно и то же
> значение поля, поэтому вторая запись просто повторяет первую. Снимется, когда
> Bitrix24 SDK научится отменять запросы.

**Принудительные версии зависимостей.** Три библиотеки временно зафиксированы в
`package.json` (раздел `pnpm.overrides`), потому что в старых версиях были уязвимости,
а обновить их обычным путём пока нельзя — их тянут другие пакеты:

| Библиотека | Снимется, когда |
|---|---|
| `brace-expansion@2`, `brace-expansion@5` | обновятся пакеты, которые их тянут (Nuxt и инструменты разработки) |
| `svgo` | обновится пакет иконок |

Это временная мера безопасности: как только «родители» подтянут исправленные
версии, фиксацию нужно убрать.

## Проверка в портале

Единственное, что нельзя проверить автоматически. Нужен доступ к тестовому порталу
Bitrix24. Отмечайте по мере прохождения:

- [ ] Установка доходит до «Готово!», кнопка появляется в чате
- [ ] Текст из чата загружается, правится и вставляется обратно
- [ ] Задача: описание загружается и сохраняется
- [ ] Комментарий CRM: загружается и сохраняется
- [ ] Пост Ленты: загружается и сохраняется, заголовок не пропадает
- [ ] Мобильное приложение Bitrix24: кнопка в чате работает
- [ ] Таблица, отправленная в чат, превращается в список (чат таблиц не поддерживает)
- [ ] В консоли браузера нет сообщений о нарушениях безопасности
- [ ] Предложение оценить приложение появляется корректно (если задан код Маркета)
- [ ] Кнопка «Сообщить об ошибке конвертации» отправляет отчёт (если задан адрес обработчика)
- [ ] Интерфейс на языке портала: проверить, что нет служебных названий строк вместо текста (см. дефект выше)

Отдельно после обновления платформы (июль 2026: Nuxt 4.5): пройти этот же список
целиком — автотесты зелёные, но живьём версия не проверялась.

## Как проверить сборку у себя

| Что | Команда | Ожидаем |
|---|---|---|
| Всё сразу | `pnpm check` | линтер, типы и 301 тест зелёные |
| Интерфейс | `pnpm build && pnpm test:e2e` | проверки браузера зелёные, снимки в `e2e/output/` |
| Приложение запускается | `pnpm dev` | открывается на `localhost:3000`, консоль чистая |
